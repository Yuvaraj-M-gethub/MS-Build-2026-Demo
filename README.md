# MS-Build-2026-Demo

Demo project for MS Build 2026 showcasing modern React development with Tailwind CSS.

## Projects

### 🐛 Bug Tracker App

A polished, feature-rich bug tracking web application built with React and Tailwind CSS.

**Location**: `/bug-tracker`

**Key Features**:
- ✅ Add and track bugs with title, description, priority, and status
- ✅ Filter bugs by status (All, Open, In Progress, Fixed)
- ✅ Color-coded visual badges for priority and status
- ✅ Full dark mode support with theme persistence
- ✅ Real-time statistics dashboard
- ✅ Responsive design for all screen sizes
- ✅ Polished UI with smooth animations and transitions
- ✅ 8 sample bugs included

**Quick Start**:
```bash
cd bug-tracker
npm install
npm start
```

The app will open at http://localhost:3000

## Development Approach

This project demonstrates professional web development practices:
- **Component-based architecture**: Reusable, maintainable components
- **Modern React patterns**: Hooks for state and side effects
- **Responsive design**: Mobile-first approach
- **Accessibility**: ARIA labels, focus management, keyboard navigation
- **Dark mode**: Class-based theming with Tailwind
- **State persistence**: LocalStorage for user preferences
